## Cross-stage semantic conventions

### Ambient space and measurability

The foundational layers use a real Hilbert space `E` with `NormedAddCommGroup E`,
`InnerProductSpace ℝ E`, and `CompleteSpace E`. Measure-theoretic declarations additionally use an
abstract `MeasurableSpace E`.

This does not assert that every abstract measurable structure is the Borel structure generated by
the Hilbert topology. Later Euclidean applications use the canonical measurable structure. If a
future theorem needs a topological-measurable compatibility fact, it must add or derive the
appropriate Borel hypothesis rather than treating it as implicit here.

### Test-function core

The experiment uses globally smooth, square-integrable functions with integrable squared gradient.
This is a smooth finite-energy core. No equivalence with a closed Sobolev domain, Dirichlet-form
closure, or spectral-gap definition is claimed. The selected core is sufficient for the intended
linear-test lower bound once finite second moments make linear tests admissible.

### Constants and extended values

A fixed Poincaré constant is a real number `C : ℝ` with nonnegativity included in
`HasPoincare`. The optimal constant is an `ENNReal`: finite valid constants are represented by
`NNReal`, and the infimum of an empty indexing subtype is `⊤`. Later Rayleigh quotients will also
use `ENNReal` so positive variance over zero energy can be `⊤` without importing real
division-by-zero conventions.

### Difference classification

Every comparison with the production reference must use one of these labels:

- **semantic difference:** the represented mathematical proposition or object changes;
- **API difference:** the proposition is logically unchanged, but binders, namespaces, or calling
  syntax differ;
- **proof-only difference:** declaration types agree and only the proof term or tactic changes;
- **documentation difference:** comments or navigation change without affecting Lean declarations.

Unproved equivalences must not be described as mere API differences.

- The experimental namespace remains `Issue2Autoformalization.Stage1A` so the new declarations

- The two `@[simp]` attributes are intentional API choices. Every other attribute, option override,
  or linter suppression is excluded.
- Stage 2A proves only elementary geometry. Energy, admissibility, variance, and all analytic
  consequences begin at Stage 2B.
