# Formalization maintenance register

The [remaining-family register](remaining-families.md) is the current layout and documentation
entry point: unresolved debt, accepted structural constraints, source ownership and the checks a
layout change must pass. The current source directory is the generated
[module inventory](../../formalization/MODULES.md). Dated screening inventories and the earlier
finding-by-finding register are kept outside the published tree; their counts and former paths
are not current inventory, and later layout work does not reopen their resolved findings or
advance mathematical proof or certificate status.

For a new finding, record source evidence, mathematical responsibility, consumers, proposed
placement and validation under the [classification workflow](../workflow.md). Distinguish a
confirmed problem, a candidate, an accepted exception and a resolved issue. File length and
cross-family imports alone do not justify a split or relocation. Keep existing IDs and dated
evidence intact; a proposed change is accepted only after its clients and required checks pass.
Use [HANDOFF](../../HANDOFF.md) for snapshot-specific acceptance pointers.
