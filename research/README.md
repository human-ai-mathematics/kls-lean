# Research navigation

This directory contains the English research record, paper mapping, progress views, decisions, and handoffs. The current repository state is summarized in the [current KLS handoff](../HANDOFF.md).

- [Literature register](progress/LITERATURE.md): paper versions, theorem scope, Lean statements, certificates, and coverage.
- [Progress overview](progress/README.md): current priorities, proof routes, diagrams, and links to generated views.
- [Decisions](decisions/README.md): the chronological decision-record index generated from the dated records.
- [Handoffs](handoffs/README.md): the chronological handoff index generated from the dated records.
- [Artifact inventory tool](inventory_artifacts.py) and [recoverable compiled storage](artifact_storage/README.md): reviewed retention, manifests and recovery history.
- [Current handoff](../HANDOFF.md): only the current proof, verification, controller, and next-step state.

Generated progress files remain owned by `research/progress/update.py`; this page is navigation only.
